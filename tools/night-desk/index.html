Console dossier
Purpose A night-ops instrument for N6CBL / DM03tu. Tune a VFO, read an S-meter, key Morse, watch the grayline, and plot skip from the published QRZ book.
Delivery Static HTML/CSS with vanilla JS. No build step. No telemetry. No external scripts. No cookies. No accounts. Web Audio starts on the first click or key.
Log source The paper log is /data/qso-log.json — the same QRZ Logbook cache served by /log/. This page does not invent contacts. Click a row to park the VFO and draw the hop.
Trust boundary Everything runs in your browser. The S-meter is a model (tuned-QSO proximity + RF gain + paddle), not an SDR. Sidetone is synthesized locally.

Method notes
Grayline. Sun latitude is the usual declination approximation (−23.44°·cos(2π(DOY+10)/365.24)). Sun longitude is 180° − 15°·UTC hours. The globe is an orthographic projection of /images/world-map.svg — the same equirectangular basemap as the homepage — sampled onto the sphere. Night is a twilight band where the ECEF normal dots the sun vector through zero, not a fillRect hatch. Skip. Great-circle interpolation in ECEF. Hop count is ceil(distance / band hop-km), with 80 m treated as NVIS under 600 km. It is a planning sketch, not VOACAP. S-meter. A model: RF gain sets the floor; a published QSO within 3.2 kHz of the VFO raises the needle; the paddle pins it near S9. It is not connected to a radio. Paddle. Iambic A on Z/X, straight key on Space. Decoder uses 1.2/WPM dit timing with 1.8 / 2.1 / 6.2 dit thresholds for dah, letter gap, and word gap. Sidetone is a 600 Hz sine with a 4–8 ms envelope. Log fidelity. Every row is one ADIF record from the scheduled QRZ fetch. If a contact should appear here, it belongs in QRZ first. See /log/.
